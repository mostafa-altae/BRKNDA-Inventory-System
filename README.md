## 📖 About
A professional desktop prototype application built with **Java Swing** for managing appliance inventory, processing new orders (POS), and generating invoices. This project was developed as a core requirement for the **Visual Programming** course.

## 🚀 Key Features
- ✅ **Authentication:** Secure login for Admin/Sales roles.
- ✅ **Inventory Management:** CRUD operations for home appliances.
- ✅ **POS Interface:** Real-time order processing with tax calculation.
- ✅ **Invoice Generation:** Automated billing for customers.

## 🛠️ Tech Stack
- **Language:** Java
- **Framework:** Java Swing
- **IDE:** Apache NetBeans
