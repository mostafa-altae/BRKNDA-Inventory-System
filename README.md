# BRKNDA Inventory & Orders Management System 📦

A professional desktop prototype application built with Java Swing for managing appliance inventory, processing new orders (POS), and generating invoices.

## 🚀 Key Features
* **Authentication:** Secure login interface.
* **Inventory Management:** View, search, and filter available stock.
* **Product Entry:** Add new products with detailed attributes.
* **Point of Sale (POS):** Process new customer orders and calculate totals.
* **Invoicing:** Auto-generate printable customer invoices.

* **Language:** Java
* **GUI Framework:** Java Swing
